# 05 打包发布

## 1. 方案选择

采用 **PyInstaller onedir**：

- 目录内包含 exe + `_internal` 运行库；首次启动快，排错容易；
- 不采用 onefile：onefile 每次启动先解压 200MB+ 到临时目录，启动慢、被杀软误报概率更高；
- 不引入安装器：当前作为内部评估/便携版，解压即可运行；正式发布可再包成 Inno Setup/MSIX。

## 2. 构建命令

```powershell
cd D:\obsai2026
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

脚本步骤：

1. 运行 pytest（可通过 `-SkipTests` 跳过，不建议）；
2. 生成图标（若不存在）；
3. 清理 `dist\PCB_AR_Annotator`、`build\pyinstaller`；
4. 执行 `python -m PyInstaller --clean packaging\pcb_ar.spec`；
5. 用 `Start-Process -Wait` 运行打包后的 exe：
   ```powershell
   PCB_AR_Annotator.exe --self-test --report artifacts\packaged_selftest.json --screenshot artifacts\packaged_demo.png
   ```
6. 检查退出码和报告；
7. 复制 README/docs/使用说明到发布目录；
8. 生成 `dist\PCB_AR_Annotator_v0.2.3_win64.zip` 和 `dist\CHECKSUMS.txt`。

可选参数：

```powershell
.\scripts\build.ps1 -SkipTests
.\scripts\build.ps1 -SkipZip
```

## 3. 产物说明

```text
dist/
  PCB_AR_Annotator/
    PCB_AR_Annotator.exe
    _internal/                 # Python、Qt、OpenCV 运行库
    README.md
    使用说明.txt
    docs/
  PCB_AR_Annotator_v0.2.3_win64.zip
  CHECKSUMS.txt
artifacts/
  packaged_selftest.json
  packaged_demo.png
```

用户只需解压 zip 并双击 exe；不需要安装 Python、OpenCV 或 Qt。

本机实测（v0.2.3，构建后由脚本更新）：

- onedir 目录：约 217.5 MB，211 个文件；
- zip：约 85.5 MB；
- 打包后自检：13 项检查，约 8.5 s；
- 发布目录包含 `README.md`、`THIRD_PARTY_NOTICES.md`、`使用说明.txt` 和 `docs/`（含 `10_轻量稀疏建图设计.md`）。

## 4. 打包后的自检

`--self-test` 在没有显示器的 offscreen 模式下执行：

1. 创建临时演示工程（3200×2200 合成板，28 元件）；
2. 加载全局图；
3. 运行自动候选检测；
4. 运行轻量捕获/稀疏地图保存/稀疏定位检查；
5. 用合成局部帧运行全图 ORB 跟踪，检查四角误差；
6. 构建主窗口、渲染画布和覆盖层；
7. 选中元件，打开内联编辑器，修改参数并标记已核对；
8. 保存工程、重新加载，检查元件数量；
9. 保存截图；
10. 输出 JSON 报告并以退出码表示成功/失败。

报告示例字段：

```json
{
  "frozen": true,
  "opencv": "4.12.0",
  "checks": [
    {"name": "orb_tracking", "ok": true, "detail": "state=locked, inliers=300, corner_error=0.24px"},
    {"name": "inline_edit_saved", "ok": true}
  ],
  "success": true
}
```

打包后若报错，优先看 `artifacts/packaged_selftest.json` 的 `traceback`。

## 6. 常见打包问题

### 6.1 缺少 `qwindows.dll`

PyInstaller 的 PyQt6 hook 通常会收集。若出现 “could not find or load the Qt platform plugin windows”：

- 确认 `_internal/PyQt6/Qt6/plugins/platforms/qwindows.dll` 存在；
- 检查是否有旧版 Qt 环境变量 `QT_PLUGIN_PATH` 干扰；
- 不要混用 conda/系统 Qt 与 venv 内的 PyQt6。

### 6.2 缺少 OpenCV DLL

`opencv-python-headless` 的 `cv2.pyd` 依赖同目录的 OpenCV DLL。PyInstaller 应收集到 `_internal/cv2/`。若从源码复制文件，需整体复制。

### 6.3 启动闪退、无窗口

windowed 模式没有控制台。临时构建一个 `console=True` 的调试版，或在代码中把异常写入日志：

```powershell
# 调试：临时把 packaging\pcb_ar.spec 中 console=False 改为 True 重新打包
```

日志位置：`%LOCALAPPDATA%\PCB_AR_Annotator\logs\app.log`。

### 6.4 SmartScreen / 杀毒软件

PyInstaller 未签名程序常被误报。解决：

- 购买代码签名证书（EV 证书可减少 SmartScreen 提示）；
- 用 `signtool` 对 exe 签名；
- 提交误报到杀毒厂商；
- 内部使用可添加目录白名单。

### 6.5 包体过大

当前包约 200~350 MB，主要来自 Qt6（约 75 MB 压缩前更多）和 OpenCV。可优化：

- 已使用 headless OpenCV；
- 在 spec 中排除不需要的 Qt 模块（需验证，避免误删）；
- 不捆绑 PyTorch/YOLO；
- 不收集测试/文档到运行目录（当前 docs 是人工复制，可移除）。

## 7. 发布建议

- 交付 zip + SHA256 + 使用说明；
- 在目标 Windows 10/11 x64 上实测；
- 对现场操作员提供 5 分钟培训视频/流程卡；
- 记录相机型号、分辨率、曝光、镜头、工作距离；
- 版本号写入 `pyproject.toml`、`version_info.txt`、README；
- 若对外商业分发，先解决 PyQt6 GPL/商业许可问题（见 `THIRD_PARTY_NOTICES.md`）。

## 8. 签名示例（需证书）

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 `
  /f cert.pfx /p <password> `
  "dist\PCB_AR_Annotator\PCB_AR_Annotator.exe"
```

对目录内所有 exe/dll 签名后重新压缩。

## 9. 卸载/清理

便携版无安装：

- 删除程序目录；
- 如需清除用户数据，删除 `%LOCALAPPDATA%\PCB_AR_Annotator`（含演示工程、配置、日志）；
- 用户自建工程在其他位置，不会被自动删除。
