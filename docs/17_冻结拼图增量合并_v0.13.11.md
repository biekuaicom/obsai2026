# 冻结拼图增量合并（v0.13.11）

## 核心流程

```text
第一张图 → 冻结拼图原点
后续每一张：
  C = 新图足迹 ∩ 已冻结覆盖
  只在该 C 内匹配冻结拼图
  只求一个相似变换
  内容核对
  通过 → 并入并冻结
```

## 与之前版本的区别

- 不再对单个邻居分别求候选；
- 不再先横后纵覆盖写；
- 不再对已接受图做全局重优化；
- 新的匹配对象是“已冻结拼图”本身；
- C 区是实际矩形交集，不是固定边带。
