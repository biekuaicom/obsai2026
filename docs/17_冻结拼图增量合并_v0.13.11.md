# 冻结拼图增量合并（v0.13.11）

## 核心流程

```text
第一张图 → 冻结拼图原点
后续每一张：
  C = 新图足迹 ∩ 已冻结覆盖
  只在该 C 内匹配冻结拼图
  只求一个相似变换
  内容核对
  通过 → 并入并冻结
```

## 与之前版本的区别

- 不再对单个邻居分别求候选；
- 不再先横后纵覆盖写；
- 不再对已接受图做全局重优化；
- 新的匹配对象是“已冻结拼图”本身；
- C 区是实际矩形交集，不是固定边带。

## 001 结果

- 整板基本完整；
- 大面积重复/塌陷明显减少；
- 仍有单个黑色缺口，需要继续修；

## 实现补齐（不另升版本号）

上面的流程在 v0.13.11 里只完成了一半：相似变换算出来之后只留了平移，匹配失败会按网格硬放，新图矩形还会盖掉已经冻结的重叠像素。离线网格拼接现已按同一方案补齐，包装版本仍是 `0.13.11`。

- `C = 已冻结覆盖 ∩ 当前位姿假设的足迹`。两块邻居时这块交集是 L 或十字，不是整幅预测矩形，也不是历史红区的并集。匹配前冻结图和新图都按 C 清零。
- 第一对邻居放置成功后，用它们的中心距更新这一方向的步长，后面的 C 用测得步长预测，不再一直沿用 overlap 参数的猜测。
- 仍要粗搜索时，按邻居方向上的期望重叠带打分。重叠面积更大不加分，新图滑进旧图的位置直接丢掉。
- 只在 C 内把冻结图和新图都抽成二值形状：安装孔、元件本体、焊盘/过孔、丝印块、较长走线。记录类型、中心、长短轴或直径、稳定方向。
- 先按类型和相近尺寸配对，再用相对距离和方向做星座校验，求**一个**完整相似变换（旋转、平移、轻微缩放）。孔和元件足够时，周期焊盘不参与求解。形状太少才在同一 C 里用 ORB，必要时再做一次小幅 ECC。
- 渲染和写回都使用完整 2×3。在同一 C 里核对中心残差、尺寸和灰度相关；失败就拒绝该张，不改已接受位姿，也不写入冻结图/覆盖。
- 通过后只补新图独占像素，重叠区保持先冻结的参考。蛇形顺序仍然要调用方把 `serpentine=True` 才启用。

仍可能拒绝而不是硬拼的情况：真实重叠不在大约 8%–45%；重叠里只剩周期焊盘；ORB 平移出现两个分开的峰。接缝仍是直线/L 型格子，不会回头移动已经接受的位姿。
