# 04 开发指南

## 1. 环境隔离

项目只使用项目内的虚拟环境，不写系统 Python：

```powershell
cd D:\obsai2026
powershell -ExecutionPolicy Bypass -File .\scripts\setup_env.ps1
```

脚本行为：

1. 用本机 Python 3.12 执行 `python -m venv .venv`；
2. 用 `.venv\Scripts\python.exe -m pip` 安装锁定依赖；
3. 用 `pip install -e . --no-build-isolation` 安装本项目；
4. 不会执行全局 `pip install`，不会改 PATH/注册表。

若无法访问默认 PyPI，脚本默认使用清华镜像：

```powershell
.\scripts\setup_env.ps1 -IndexUrl https://pypi.tuna.tsinghua.edu.cn/simple
```

依赖：

- 运行时：PyQt6 6.9.1、opencv-python-headless 4.12.0.88、NumPy 2.2.6。
- 开发/打包：pytest 8.4.2、PyInstaller 6.16.0。
- 使用 `opencv-python-headless` 而不是 `opencv-python`，避免 OpenCV 自带 Qt 插件与 PyQt6 冲突。

## 2. 运行

```powershell
.\scripts\run.ps1
# 或指定工程
.\scripts\run.ps1 --project "D:\boards\demo.pcbproj.json"
# 强制演示
.\scripts\run.ps1 --demo
```

等价的直接命令：

```powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe -m pcb_ar
```

## 3. 测试

```powershell
.\scripts\test.ps1
```

它做两件事：

1. `pytest -q`：核心算法 + 离屏 UI；
2. `python -m pcb_ar --self-test ...`：与打包后相同的全链路自检。

单独跑：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
$env:QT_QPA_FONTDIR = "$env:WINDIR\Fonts"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pcb_ar --self-test --report artifacts\selftest_report.json --screenshot artifacts\demo_main.png
```

注意：离屏截图需要 `QT_QPA_FONTDIR` 指向系统字体目录，否则 Qt offscreen 插件找不到字体，中文会显示成方框。正常桌面运行不需要该变量。

```text

    sparse_capture.py    # 默认轻量捕获：稳定/覆盖/重叠/关键帧

  ui/

    inline_editor.py     # 画布内联 3 参数编辑
    scan_dialog.py       # 全图扫描工作台、拼图线程（备用）
```

### 4.1 不变量

- `core/` 不导入 `PyQt6`，保证算法可独立测试。
- 工程数据只在 UI 线程修改。
- 一个 `LiveWorker` 只能启动一次；切换输入必须新建线程。
- 元件 `core` 永远补齐/截断为 3 个槽位。
- 所有全局坐标都是总览图像素；物理 mm 只在显示/导出时换算。
- 跟踪矩阵方向固定为 **总览 → 实时帧**。
- 稀疏地图的 keyframe pose 方向固定为 **关键帧像素 → 总览像素**。
- 轻量工程默认 `map_mode="hybrid"`；`sparse_map` 为空时回退全图。
- 拼接/裁剪得到的 numpy 视图可能是非连续的；送 QImage 前必须 `ascontiguousarray`。

### 4.2 添加新的检测器

实现类似接口：

```python
class MyDetector:
    def detect(self, global_image: np.ndarray) -> list[Detection]:
        ...
```

在 `MainWindow.auto_detect()` 中替换 `detect_component_candidates`，或用配置选择器。返回 `Detection(bbox, score, label, category, confidence)` 即可复用现有候选/核对流程。

### 4.3 接入 XYZ 机台

目标：用机台坐标替代 ORB 矩阵，不修改 UI。

1. 新建 `core/machine_pose.py`：
   - 串口/网口读取 `(x_mm, y_mm, z_mm, theta_deg)`；
   - 根据标定得到 `mm_per_px`、全局图原点与旋转；
   - 输出 `M = world_to_live`。
2. 在 `MainWindow` 中把 `GlobalLocalTracker` 替换为 `MachinePoseSource` 适配器，保持 `TrackResult` 字段（`matrix/state/confidence/...`）。
3. 机台模式还应处理：
   - Z 高度变化导致的比例缩放；
   - 轴反向/零点偏置；
   - 通信超时 → `stale`；
   - 软限位/急停状态。

建议先保留 ORB 作为校验：机台矩阵与视觉矩阵的四角误差超过阈值时报警。

### 4.4 训练 YOLO

1. 采集真实相机图像（不同光照、板型、遮挡），用 CVAT/Label Studio 标注 `resistor/capacitor/ic/connector/diode/...`。
2. 导出 YOLO 数据集，训练 `yolov8n/s` 或更新版本。
3. 安装 `ultralytics`（不要打进默认安装包），把权重放 `weights/pcb_best.pt`。
4. 用 `YoloDetector` 替换传统检测器；建议保留“低置信度候选”人工确认。

评估指标：mAP50、每类召回、误检率、单帧耗时。对产线，优先保证召回，再通过人工核对降误检。

## 5. 调试技巧

- 日志：`%LOCALAPPDATA%\PCB_AR_Annotator\logs\app.log`。
- 离屏调试 UI：设置 `QT_QPA_PLATFORM=offscreen`，运行 pytest。
- 保存失败：检查工程目录权限/全局图是否被移动。
- 跟踪调参：`config.json` 修改后重启；或在测试中构造 `TrackerConfig`。
- 帧率低：先用 `SyntheticMicroscopeSource` 复现，再检查是生成、跟踪还是 UI 绘制瓶颈。
- 标签重叠：`overlay.py::_candidate_positions` 是布局入口；可加入更复杂的避让/聚类。
- 中文字体：正常 Windows 使用微软雅黑；打包版若在精简系统上缺字体，需要自带字体（注意字体许可）。

## 6. 代码风格

- Python 3.12，类型提示尽量完整。
- 核心逻辑不依赖全局 Qt 状态。
- 新的数值阈值放进 `Config` 数据类，不要散落魔法数。
- 修改坐标变换时，先补 `tests/test_geo.py` 和跟踪测试。
- UI 操作要有状态栏反馈；会阻塞 >100 ms 的操作放线程或 `QApplication.processEvents`（仅短操作）。

## 7. 性能基准

当前机器（Windows 10，具体 CPU 未记录）实测：

| 操作 | 时间 |
|---|---|
| 轻量捕获 3 关键帧 → 1578×640 增量总览 | 每张合并约 0.2~0.4 s；收尾 ~0.02 s |
| 稀疏定位单帧（1600×1000，工作宽 1200） | ~50~60 ms |
| 全图 ORB 初始化（3200×2200 → 1800 宽，5000 点） | ~70 ms |
| 跟踪单帧（1600×1000，工作宽 1200，1600 点） | 43~50 ms |
| 演示实时帧率 | 15.8 FPS |
| 28 关键帧扫描渲染（1203×2689） | 3.2 s |
| 离屏全链路自检 | 6~7 s |

性能优化优先级：跟踪特征数 > UI 绘制 > 拼图渲染。真实 4K 相机还会增加采集/缩放成本，建议现场实测。

## 8. 开发环境注意事项

- 不要在系统 Python 安装本项目依赖；所有命令显式使用 `.venv\Scripts\python.exe`。
- `QT_QPA_FONTDIR` 仅用于 offscreen 截图/自检，不要写入系统环境变量。
- 构建产物写入 `build/`、`dist/`；不要提交 `.venv`。
- 真实板图和 BOM 含商业信息，发布前清理 `artifacts/` 和 `%LOCALAPPDATA%` 中的演示数据。
