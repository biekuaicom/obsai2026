# 06 硬件集成与演进

## 1. 当前硬件假设与验收缺口

本版在合成板上验证了算法链路，**没有在真实 800 万像素相机、显微镜、手动平台或 XYZ 机台上验收**。现场落地前必须完成：

- 相机实际分辨率/帧率/曝光测试；
- 镜头视场、工作距离、景深、畸变测试；
- 环形光/同轴光下的反光与阴影测试；
- 手动平移/旋转速度下的跟踪稳定性测试；
- 全板扫描的拼图接缝与漂移测试；
- 与 BOM/位号的人工核对效率测试。

## 2. 相机与光学

### 2.1 分辨率与视场

800 万像素常见为 3840×2160（16:9）或 3264×2448（4:3）。若视场为 60 mm × 34 mm：

- 3840 px / 60 mm = 64 px/mm（约 0.0156 mm/px）；
- 一个 0603 元件（1.6×0.8 mm）约 102×51 px，足够稳定识别/标注；
- 但本程序显示/跟踪会降到 1600/1200 宽，等效约 27/20 px/mm。对于“框选和参数叠加”足够；若需要自动识别小元件，建议提高工作宽度或使用 ROI 高分辨率复核。

### 2.2 镜头

- 优先 **远心镜头**：消除透视/视差，PCB 高度差异不会导致框漂移。
- 普通工业镜头需做棋盘格畸变校正；本版未内置校正，边缘误差可能明显。
- 工作距离固定，避免操作中 Z 大幅变化；若必须变焦，相似变换的 scale 会吸收一部分，但标注框尺寸/位置精度会下降。

### 2.3 光照

- 同轴光/环形光：减少焊盘反光；反光会吞掉丝印/特征。
- 偏振片可压制金属反光。
- 曝光时间尽量短，减少运动模糊；必要时用频闪同步。
- 不同批次板颜色差异大时，传统检测器的颜色阈值需要调整。

## 3. 机械与坐标

### 3.1 当前手动显微镜

- 相机的平移/旋转被视觉跟踪吸收，不需要编码器。
- 建议在视场内保留至少一个定位孔/连接器/丝印字符，作为稳定特征。
- 操作速度：目标 < 1 个视场/秒；快速甩动会跟丢。

### 3.2 迁移到 XYZ 机台

当相机装在 XYZ 轴上，可关闭 ORB，直接由机台坐标计算叠加矩阵：

```text
q_live = S(z) · R(-θ) · (g_global - t_machine) / mm_per_px
```

其中：

- `S(z)`：Z 高度导致的像素比例；
- `R(-θ)`：相机/轴旋转；
- `t_machine`：机台当前 XY 对应的全局图原点偏移；
- `mm_per_px`：标定比例。

需要的标定：

1. 全局图坐标系原点、X/Y 方向；
2. 轴反向/零点；
3. `mm_per_px`（走已知距离，测像素位移）；
4. Z 与比例关系（多个高度采标）；
5. 相机安装旋转角。

建议保留视觉跟踪作为**校验**：机台矩阵与视觉矩阵的四角误差超过阈值时报警，防止标定错误/丢步。

### 3.3 通信协议建议

与 PLC/单片机/GRBL 通信时，至少需要：

- 周期位置帧：`X,Y,Z,θ,status,timestamp`；
- 心跳/超时（>100 ms 判 stale）；
- 软限位/急停状态；
- 坐标系/单位明确（mm、度）；
- 断线重连与日志。

建议协议带 CRC 和序号，避免半帧/乱序。

## 4. 扫描建图的工程化改进

### 4.1 回环闭合

当前是开环累加。改进方案：

1. 扫描中保留关键帧位姿；
2. 新关键帧不仅匹配上一帧，也与距离较远但可能重叠的历史关键帧匹配；
3. 构建位姿图，节点=关键帧，边=相对变换；
4. 用 g2o/Ceres/scipy 做最小二乘优化；
5. 重新渲染拼图。

对 PCB 这种平面场景，回环检测可用定位孔/连接器等唯一特征辅助，减少重复焊盘误匹配。

### 4.2 自动覆盖路径

手动扫描依赖操作员。接机台后可按栅格路径自动移动并抓图：

- 依据视场大小和 25% 重叠生成路径；
- 每站停稳/频闪拍照，避免运动模糊；
- 用机台坐标作为初值，视觉只做微调；
- 可做到“一键整板建图”。

### 4.3 多分辨率

- 建图用中分辨率（1280/1600）保证速度；
- 对关键区域（小元件、密引脚）可再拍高分辨率 ROI；
- 全局图与局部高清图通过变换关联；
- 标注框在全局图坐标，显示时按 ROI 映射。

## 5. 自动识别的落地路径

### 5.1 传统候选（当前）

优点：无需训练数据、CPU 快、可解释。
缺点：不分类、参数不可读、对颜色/反光敏感。

适合：先跑通“建图—标注—核对”流程。

### 5.2 YOLO（建议下一步）

1. 采集至少 500~1000 张真实局部图，覆盖不同板型/光照/角度；
2. 用 CVAT/Label Studio 标框+类别；
3. 训练 YOLOv8/11 nano/small，输入 640/960；
4. 在全局图上滑窗或对实时帧检测，再用跟踪矩阵映射到全局；
5. 低置信度候选交人工；
6. 用 TensorRT/OpenVINO 加速（可选）。

注意：

- 训练数据必须来自实际相机，不能用合成图直接上现场；
- 类别不平衡（大量电容/电阻）要做重采样；
- 误检成本低、漏检成本高，阈值偏召回；
- 模型版本、权重、类别表要随工程记录。

### 5.3 参数/位号识别

可叠加 OCR（PaddleOCR/Tesseract）读取丝印，但：

- 丝印可能被遮挡/模糊/反光；
- 字库和字体多样；
- OCR 结果只能作为候选，必须人工确认；
- 需要与 BOM 做模糊匹配。

建议优先级：YOLO 分类/框 > OCR 位号 > BOM 匹配。不要在没有人工核对的情况下自动写参数。

## 6. 精度指标与验收

建议定义：

- **跟踪稳定性**：静止 10 s，框中心抖动 < 2 px；平移 100 mm，最大滞后 < 10 px。
- **绝对定位**：与人工标记的 10 个基准点比较，平均误差 < 0.2 mm（或 5 px，取严）。
- **重捕时间**：遮挡 1 s 后 < 0.5 s 恢复。
- **拼图接缝**：无明显重影；定位孔中心偏差 < 3 px。
- **核对效率**：每 100 个元件的人工核对时间相对纯手工下降 ≥ 50%。

需在真实板上测量，不要用合成数据替代。

## 7. 路线图

### V0.1
- 视频扫描建图、ORB 跟踪、AR 标注、3 参数内联、右侧栏、BOM、打包。

### V0.2（本版）
- 默认轻量引导捕获：稳定/清晰检查、红色覆盖、重叠校验；
- 稀疏关键帧地图 + ORB/边缘定位；
- 稀疏 + 低分辨率全图周期校验/回退；
- 全图扫描保留为备用/增强。

### V0.3（现场可用）
- 相机参数面板/标定；
- 回环闭合或分段建图；
- 覆盖质量报告（空洞、重叠率过低、模糊关键帧）；
- 标签避让/聚类优化；
- 自动保存/恢复；
- 真实硬件调参预设。

### V0.4（产线）
- XYZ 机台协议；
- YOLO 分类/检测 + OCR 候选；
- 权限/审计日志；
- 多板型模板/BOM 版本管理；
- 精度报告与 SPC；
- 代码签名/安装器；
- PySide6 迁移或许可证采购。

## 8. 风险清单

| 风险 | 影响 | 缓解 |
|---|---|---|
| 反光/低纹理 | 跟踪丢失 | 偏振/同轴光；保留定位孔；提高特征数 |
| 扫描漂移 | 拼图错位 | 放慢、增加重叠、回环闭合、分段 |
| 镜头畸变 | 边缘框偏移 | 远心镜头/畸变校正 |
| 相机被占用 | 无法采集 | 关闭厂商软件；错误提示 |
| 800W 4K 性能 | 帧率低 | 降采样；ROI；GPU/OpenVINO |
| 误检/漏检 | 人工增加 | 人工核对；YOLO 训练；置信度阈值 |
| PyQt6 GPL | 商业分发合规 | 采购许可/迁移 PySide6 |
| 未签名 | SmartScreen 拦截 | 代码签名 |
