## 2. 首次验收（10 分钟）

1. 解压 zip 到无中文/空格的短路径（例如 `D:\PCB_AR`）。
2. 双击 exe。首次启动会生成演示工程并自动播放。
3. 观察 30 秒：参数气泡应随元件移动，框应保持贴合；状态栏应显示跟踪内点与 FPS。
4. 单击 U3 → 双击气泡 → 修改 3 个参数 → Enter。
5. 右侧栏点击「标记已核对」→「下一待核对」。
6. Ctrl+S 保存到 `D:\PCB_AR\test.pcbproj.json`，关闭并重新打开，确认参数与状态保留。
7. 点击「轻量扫描建图…」→ 开始捕获 → 停稳拍第一张 → 移动并保留红色覆盖 → 拍 2~3 张 → 完成并建立地图。
8. 检查预览中的红色覆盖和总览；导入新工程后启动摄像头/演示，确认状态栏显示“稀疏定位/全图增强”。
9. 用另一台无 Python 的 Windows 10/11 x64 重复步骤 1~3。

## 3. 环境隔离确认

本项目没有修改系统 Python。验证：

```powershell
# 系统 Python 不应有 pcb_ar / PyQt6
C:\Users\<user>\AppData\Local\Programs\Python\Python312\python.exe -m pip list | findstr /I "pcb-ar PyQt6 opencv"

# 项目虚拟环境
.\.venv\Scripts\python.exe -m pip list | findstr /I "pcb-ar PyQt6 opencv"
```

配置/日志/演示数据在 `%LOCALAPPDATA%\PCB_AR_Annotator`；删除该目录即可清理用户数据。

## 4. 现场测试记录模板

建议每个现场板记录：

- 相机型号/分辨率/曝光/镜头/工作距离；
- 视场 mm 与 `mm_per_px`；
- 10 个基准点的跟踪误差（px、mm）；
- 跟丢次数、重捕时间；
- 整板扫描关键帧数、拼图尺寸、接缝误差；
- 自动候选召回/误检；
- 100 个元件的核对耗时；
- 4K 下 CPU/内存/帧率；
- 失败样本截图。

## 5. 当前不建议直接投产的点

- 未用真实 800W 相机/显微镜验收；
- 扫描无回环闭合，长扫描可能漂移；
- 自动检测只输出候选，不识别类别/参数；
- 未做代码签名；
- PyQt6 许可未解决（商业闭源分发前必须处理）；
- 未接 XYZ 机台/串口。

## 6. 下一步建议顺序

1. 真实相机接入与 1 小时稳定性测试；
2. 采集 300~500 张真实图，调传统检测/训练 YOLO；
3. 实现回环闭合/分段扫描质量控制；
4. 接 XYZ 轴坐标（保留视觉校验）；
5. 做许可/签名/安装器，再进入产线试用。
